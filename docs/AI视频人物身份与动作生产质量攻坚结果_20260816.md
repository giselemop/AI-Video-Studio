# AI Video Studio 人物身份与动作生产质量攻坚结果（2026-08-16）

## 结论

最终生产门禁：**NO_GO**。

本轮已经把角色候选生成、自动 QA、Golden Pack 校验、Selector v2、动作复杂度拆分、真实 HTTP 路由和 25 秒技术片串起来；但人物身份多视角、复杂动作语义、真实 Driving/Pose 输入和目标大模型部署仍未达到生产通过条件。技术链路成功不等于人物身份或动作语义通过。

自动视觉结果全部带 `manualReviewRequired=true`。当前机器没有 InsightFace/ArcFace、真实 landmark 或人体/手部语义模型，因此 `IdentityScore` 和视角结果是 CPU raster/face-region proxy，不能替代人工审核。

## 环境与边界

- Windows 本机；RTX 4070，显存总量约 12282 MiB；ComfyUI 0.31.0；FFmpeg 可用；GPU 最终复查空闲约 1725 MiB，随任务变化。
- 主 API `127.0.0.1:18080` 仍由既有 published process 提供；本轮没有强行重启它。新增路由使用独立 Release `RouterProbe` sidecar 在 `127.0.0.1:18084` 进行真实 HTTP 验证，并在验证后停止临时进程。
- 未下载或覆盖 Wan2.2 Animate / HunyuanVideo-1.5 权重；未把 ComfyUI 节点存在误报成模型可运行。
- 保留既有未提交工作，没有执行 reset、clean 或广泛删除。

## 人物身份流水线

### 首轮 50 张候选

- `front` 6/6 通过自动门槛；其他请求视角全部检测为 Front 并因 `WrongViewAngle` 拒绝。
- 自动通过样本的 `identityScore` 约 0.98、`faceQualityScore` 1.0、`overallScore` 约 0.95；这些是 proxy 分数，不是 ArcFace/InsightFace 相似度。
- 视角分类已经有显式 `Front / Unknown` 和 `ViewAngleUnverified / WrongViewAngle` 标记；没有把 prompt 中的 “30/45 度” 当作实际角度。

### 定向视角补测

- TV01 Left45：生成成功，QA `Unknown`，identity proxy 0.79，拒绝。
- TV02 Right45：生成成功，QA `Unknown`，identity proxy 0.69，拒绝。
- TV03 HalfBody：生成成功，出现明显重影/双脸，QA `Unknown`，拒绝。
- TV04 FullBody：生成成功，但头顶/脚部不完整，QA `Unknown`，拒绝。

因此本轮没有把错误的多视角候选写入 Golden Pack，也没有启动 LoRA 训练。

## 动作与路由

`MotionComplexityAnalyzer` 和 `ModelRouter` 已接入服务端：

- `blink and breathe` → `Simple` → `12_ltx_face_stable_v3`，不拆分。
- `turn then sit` → `Complex` → `split-shot-gated`，必须拆分并保留子镜头建议。
- `driving posture` → `Complex` → `wan2.2-animate`，`NeedSplit=true`，同时返回本地目标权重/workflow 不可用的阻塞原因。
- 复杂多动词、Walk/Sit/Pick/Driving 不再静默走普通单镜头路径。

本轮新生成的 24 个 Simple Motion 和 27 个 Walk/Sit/Pick 文件均保留原始 seed、prompt、耗时和人工审核状态；抽查帧显示许多 Walk/Sit/Pick 输出仍是近景，不能冒充全身走路、坐下或手物接触。

## 目标模型部署证据

已有本机 loader probe 的结论仍有效：

- Wan2.2 Animate 14B 目标文件不在本地 loader 列表；ComfyUI 虽列出 `WanAnimateToVideo` / `WanAnimate2ToVideo`，但没有可提交的权重/workflow/Driving Video 输入。
- HunyuanVideo-1.5 目标文件不在本地 checkpoint 列表；`HunyuanVideo15ImageToVideo` 节点存在，但真实提交在 loader validation 阶段返回 `value_not_in_list`。
- 现有 Wan2.2 TI2V 5B 基线可运行，但不能冒充 Animate；目标推理未进入 GPU sampling，因此阻塞证据不是伪造的 OOM。
