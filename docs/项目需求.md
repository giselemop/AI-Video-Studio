> 需求事实来源为当前代码、已有文档、实际运行结果和用户明确要求。代码中疑似存在但无法证明为正式需求的能力写为“待确认”。

## 一、项目背景

用户需要在 Windows 本机使用现有 ComfyUI、模型、工作流和 FFmpeg 制作 AI 图像/视频，并逐步从单镜头实验进入剧本、角色、场景、Shot、QA 和 Episode 管理。项目必须可在中断开发后由新的 AI 会话恢复，不能依赖历史聊天作为唯一事实。

## 二、项目目标

- 统一管理 AI 短剧/视频生产对象和生产状态。
- 用真实 ComfyUI/FFmpeg/TTS 任务形成可追溯输出。
- 在 RTX 4070 12GB 上保持可运行的低显存生产策略。
- 以技术 QA、内容 QA、人工审核和发布锁阻止未验收成片进入 Master。
- 形成跨电脑、跨会话可恢复的中文项目档案和验收记录。

## 三、用户角色

- 当前已确认角色：受监督的本机单一操作者。
- 业务概念角色：制作者、审核者、查看者；当前没有账户、RBAC 或真实多用户隔离实现。
- 待确认：是否需要 Admin、Producer、Reviewer、Viewer；谁能修改 LLM、删除资产、解锁 Episode、重跑和导出。

## 四、核心业务流程

~~~~mermaid
flowchart LR
  A[项目与 Episode] --> B[角色/场景资产]
  B --> C[剧本与 Shot]
  C --> D[Prompt 与关键帧]
  D --> E[ComfyUI I2V]
  E --> F[技术/Shot QA]
  F --> G[FFmpeg 增强]
  G --> H[TTS/SRT/SFX/BGM]
  H --> I[Episode QA 与人工审核]
  I --> J[Approved 锁定与 Master]
~~~~

## 五、功能模块

- 项目、Episode、角色、场景、参考图和资产。
- 剧本、版本、规则/LLM 分析和 Shot 草稿。
- Prompt 组合、编辑、锁定、历史和回滚。
- 工作流/模型/LoRA 扫描与 4070 参数。
- 关键帧候选、I2V、任务队列、依赖、取消、重试和恢复。
- Technical QA、Shot QA、Episode QA、人工审核和 Master 导出。
- Windows TTS、字幕、音效、BGM 和 FFmpeg 混音。

## 六、功能需求

### 已确认并已实现

- 项目、Episode、Shot 和资产可通过 API/工作台管理。
- 剧本可保存、版本化并分析为 Shot 草稿。
- Prompt 可组合、修改、锁定、查看历史和回滚。
- 生成任务必须真实调用 ComfyUI，并保存输出与状态。
- QA 必须区分硬失败、需要人工复核和通过；Approved Episode 才能导出 Master。
- 低显存策略：GPU 任务串行，源视频低分辨率，最终由 FFmpeg 输出 1080P/30 FPS。

### 已确认但部分完成

- 角色/场景一致性需要参考资产和人工验收；严格身份模型尚未安装。
- 音频、字幕、SFX/BGM 需要按具体 Episode 做真实成片验收。
- 失败任务需要分类、重试和保留证据；完整分布式幂等和租约尚未实现。

## 七、非功能需求

- 性能：在 RTX 4070 12GB 上 GPU 并发 1；不得默认引入需要 24GB 以上显存的模型。
- 安全：密码、Token、API Key 不进 Git、日志、报告或聊天输出；服务默认只监听回环。
- 稳定性：真实任务、输出文件、数据库状态和 QA 结果必须一致；服务重启后不能伪造成功。
- 可维护性：重要状态、需求、决策、验收和变更必须写入仓库档案。
- 数据安全：迁移前备份；禁止无确认清库、删表、删除业务媒体或直接改成功状态。
- 可恢复性：新会话应先读项目档案、Git 和实际代码，恢复当前开发节点。

## 八、已确认需求

- 使用现有 C:\install\AI\ComfyUI、C:\install\AI\Models、C:\install\AI\Workflows、C:\install\AI\Data 和 C:\install\FFmpeg。
- 不把模型权重、生产媒体、备份、日志和本地秘密提交到仓库。
- 保持 MySQL 为权威状态源。
- 继续以本机受监督研发为当前发布边界。

## 九、待确认需求

- 是否需要局域网或公网访问。
- 账户、角色、登录/配对和审计 UX。
- 外部 LLM provider、域名 allowlist、预算和数据外发政策。
- 磁盘配额、保留期、备份目标和恢复时间目标。
- 真人肖像/声音、第三方素材和模型许可证、内容审核、水印/provenance。
- 是否需要多 GPU、远程 worker、自动导演、自动音效或口型同步。

## 十、不在当前范围内的功能

以下不属于本轮和当前本机核心范围，不应被误写为未完成的核心 Bug：

- 公网多租户产品、远程管理页面、多 GPU/远程 worker。
- 自动导演、自动音效生成、高级口型同步。
- 未经用户确认的模型下载、训练或替换技术栈。
- 任何未提供实际模型文件、许可证和验收标准的身份控制能力。
