# AI Video Studio 使用说明

## 第一次启动

`C:\install\AI\VideoStudio\start.bat` 是唯一入口。它只使用本地目录内的 ComfyUI、模型、工作流和 FFmpeg；管理页面只监听 `127.0.0.1:18080`。

当前已配置并验收本机 MySQL。如果在新机器或复制后的环境中系统页显示“数据库待配置凭据”：

1. 复制 `C:\install\AI\VideoStudio\config\local.env.example` 为 `local.env`。
2. 将现有 MySQL 账号密码填入 `AI_VIDEO_STUDIO_DB_PASSWORD`。
3. 运行 `scripts\init_database.ps1`。
4. 重启 `start.bat`。

不会为了本系统重置 MySQL root 密码，因为这可能影响电脑上的其他数据库项目。真实密码只保存在未跟踪的 `config\local.env`，不会写入日志或报告。

## 推荐生产顺序

1. 在“角色资产”创建角色，填写脸型、发型、服装和固定提示词，上传正面身份锚点。
2. 在“场景资产”创建车厢、驾驶室、城市或自然环境，上传主场景图。
3. 在“项目制作”创建项目和集，按镜头卡填写动作、镜头语言、参考图、seed、尺寸和帧数。
4. 有参考图时选 Image To Video；没有参考图时先生成图片，再把图片路径放入下一个镜头。
5. 到“任务中心”观察排队、显存峰值、耗时和错误。大任务始终串行。
6. 在“素材中心”检查结果；整集镜头完成后点击“合并本集”。

## 4070 12GB 推荐参数

| 用途 | 宽高 | 帧数 | 帧率 | 建议 |
| --- | ---: | ---: | ---: | --- |
| 人物关键帧 | 768×512 或 512×320 | 1 | - | SD1.5，steps 20-28，CFG 5.5-7 |
| LTX 图生视频 | 512×320 | 73/97/121 | 24 | 约 3/4/5 秒，串行执行 |
| 最终增强 | 1920×1080 | 按源视频 | 30 | 去闪烁、插帧和超分由 FFmpeg 执行 |

12GB 显存不建议同时加载多个 Wan/Flux/超大视频模型。若发生 OOM，先降到 448×288、73 帧，再逐步恢复分辨率和时长。

## 角色一致性

目前系统会保存身份锚点、固定提示词、LoRA 路径和参考图关系。当前扫描到的 LoRA 数量为 0，尚未安装 IP-Adapter 或 ControlNet，因此“同一个人”仍需通过同一张关键帧、同一 seed、相同服装/发型提示词保持；要达到更严格一致性，按 `NEXT_STAGE.md` 增加专用身份控制模型，并继续保持单人、半身、固定光线的镜头设计。

## 错误处理

- ComfyUI 离线：检查 `C:\install\AI\VideoStudio\logs\comfyui_error.log`，或重新运行 `start.bat`。
- 数据库未连接：检查 MySQL 3306、填写 `config\local.env`，再运行 `scripts\init_database.ps1`；脚本会先备份再迁移。
- 显存不足：任务会等待显存门禁；仍失败时会按重试次数重排，并在任务中心保留错误。
- FFmpeg 失败：确认 `C:\install\FFmpeg\bin\ffmpeg.exe` 和 `ffprobe.exe` 存在，查看 `logs\server.log`。
