# 人物脸部质量诊断与最小优化报告（2026-08-11）

## 结论

当前问题不是单一阶段故障，而是两个问题叠加：

1. 静态图阶段存在随机失败，主要由人物工作流被错误套用横幅尺寸、Prompt 含混合中文/`full_body`/过多场景信息，以及没有人脸细化节点造成。
2. I2V 阶段存在独立的画幅和时序风险。首帧与视频画幅不匹配会直接裁掉眼睛；即使画幅匹配，Wan2.2 在部分 seed 上仍会出现中后段时序彩色伪影。

因此不能只修 Prompt，也不能只换视频模型。第一优先级是锁定静态人物画幅和首帧比例；第二优先级是把参考图镜头切到 LTX character-lock；第三优先级才是扩大动作、时长和镜头运动。

## 已实施的最小改动

### 1. 静态人物画布保护

`ComfyUiClient.PatchWorkflow` 识别原生 640×832 的人物 EmptyLatentImage，不再把镜头的 512×320 横幅参数补丁写入人物流程。回归任务 576 故意提交 512×320，但实际输出为 640×832。

### 2. I2V 首帧比例和时长保护

`GenerationQueue` 在提交 ComfyUI 前读取首帧尺寸：

- 竖幅首帧 → 320×416
- 横幅首帧 → 512×320
- 接近方形 → 384×384

当任务超过 121 帧且没有显式 `allowLongVideo=true` 时，稳定档自动限制为：竖幅 49 帧，横幅 121 帧，并把修正后的参数写回任务 JSON、记录 `video.parameters.normalized` 事件。LTX 的 `frame_idx` 同步限制在实际帧数范围内。

### 3. 人物 Prompt/Negative 加固

静态和视频默认词增加了：单人构图、清晰且对齐的瞳孔、自然眼睑、自然嘴唇和下颌、禁止重复脸/拼贴/contact sheet/split screen，以及 I2V 的禁止裁脸、比例不匹配、快速变焦/摇移/环绕。

### 4. Wan 默认起始档位收紧

Wan API 工作流默认回到 512×320、49 帧；带参考图时由服务自动切换 LTX character-lock，并按首帧比例补丁尺寸。没有安装新模型、新节点或新环境。

## 推荐生产工作流

```text
角色单人身份锚点
        ↓
SD1.5 人物静态图（640×832，半身/中近景，2–4 候选）
        ↓ 人工选一张脸、眼睛、嘴和发型都通过的首帧
        ├─ 无参考图、短小动作：Wan2.2，按首帧比例，49 帧起步
        └─ 有角色参考图/竖幅人物镜头：LTX character-lock，320×416，73–121 帧
        ↓
首/中/尾帧抽检：眼睛、嘴、脸型、发型、肤色、伪影
        ↓
通过后再扩大动作、镜头运动或时长；不通过只换 seed/首帧/参考图
```

人物参考图必须是“单人、单脸、无遮挡、正面或 3/4、背景干净”的一张图。当前 `C:\install\AI\Data\Characters\8\ref_20260810_002133_d7c16498.png` 是多格人脸拼图，不能作为稳定身份锚点；应替换为单脸图，不能继续把多格拼图送入身份约束链路。

## RTX 4070 12 GB 参数建议

静态图：

- 首选 640×832；脸部仍不稳时先固定半身/中近景，不先放大到更高分辨率。
- 30 steps、CFG 5.5–6.0、DPM++ 2M/Karras。
- 每次 2–4 个 seed；明确排除 collage/contact sheet/duplicate face/extra eyes。
- FaceDetailer/ADetailer 当前不可用，不通过安装整套环境解决；先靠原生 SD1.5 + 正确画布 + 候选筛选。

视频：

- 无参考图：Wan 先用 49 帧；画幅严格跟首帧，锁定镜头或极慢推近，动作幅度小于 10°。
- 有参考图：LTX character-lock 优先 73–121 帧、24 FPS、320×416 竖幅；参考图使用单脸锚点。
- 连续 2–3 个短片通过后，再尝试 5 秒或更复杂动作；不要直接从 7.5–10 秒和强镜头运动开始。
- 任何模型都不把一次成功当作稳定，至少检查首/中/尾三帧并保留失败 seed。

## 后续验收用例

1. **静态候选集**：同一角色、同一 Prompt，4 个 seed；记录可用数、重复脸、眼睛、嘴部、发型和身份特征。
2. **同图画幅 A/B**：同一首帧、同一 seed，只比较 320×416 和 512×320；512×320 应被拒绝或自动归一化。
3. **Wan 短动作集**：同一首帧、3 个 seed、49 帧、锁定镜头；检查首/中/尾帧和中间彩色伪影。
4. **LTX 参考集**：同一首帧 + 同一单脸参考图，73/121 帧；检查眼睛、嘴型、脸宽、发际线和衣服是否保持。
5. **连续镜头集**：同一角色 5 个镜头，只允许改变场景和小动作，不改变身份锚点；人工 1–5 分记录身份一致性。
