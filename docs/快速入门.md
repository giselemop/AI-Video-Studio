# AI Video Studio 30 分钟快速入门

这份说明按当前页面和当前 API 编写。第一次使用建议先用 5 个镜头、每个 3-5 秒测试，再批量扩展。RTX 4070 12GB 只让 GPU 队列串行运行。

## 0. 启动与数据库

1. 确认 `C:\install\AI\VideoStudio\config\local.env` 中已经填写现有 MySQL 密码；当前正式环境已完成此配置。
2. 首次安装或升级时运行 `C:\install\AI\VideoStudio\scripts\init_database.ps1`；脚本会先备份可用数据库，再应用基础结构和 QA 迁移。
3. 双击 `C:\install\AI\VideoStudio\start.bat`，打开 `http://127.0.0.1:18080`。
4. “系统设置”中确认 MySQL、ComfyUI、FFmpeg/FFprobe 可用；当前 `/api/health` 已验证这三项在线，TTS 音色接口也可用。TTS 不可用只会禁用配音，不阻止图片和视频生产。

## 1. 创建项目和 Episode

进入“项目制作”，点击“新建项目”，例如填写“末日科幻列车”。创建 Episode，默认输出 1920×1080、30FPS；源视频仍建议先用 512×320，最终由 FFmpeg 统一输出。

在项目制作台选择 Episode 后，顶部的“剧本拆分”“生产中心”入口会使用当前 Episode。

## 2. 创建角色和场景

在“角色资产”创建林雪、陈默等角色，填写脸部特征、发型、服装、固定提示词，并上传身份锚点。在“场景资产”创建驾驶室、车厢等场景并上传主图。

剧本解析发现未登记人物时只生成“Character Missing”草稿；发现未登记场景时只生成“Scene Draft”。确认后再到资产库正式创建，不会自动污染正式角色库。

## 3. 输入剧本并自动拆分

进入“剧本拆分”，点击“新建剧本”，选择项目和 Episode，把 TXT/Markdown 内容粘贴到文本框。例如：

```text
场景 1：末日列车驾驶室，夜晚，暴雨，近景，镜头缓慢推近，5秒。
林雪：列车还在运行，我们还有机会。
陈默握紧扶手，转头看向窗外，神情紧张。

场景 2：列车车厢，夜晚，中景，镜头跟随，5秒。
陈默：前方隧道还有两分钟。
林雪向控制台走去，抬手检查红色警报灯。
```

点击“保存剧本”，再点击“AI 拆分”。如果已经配置 LLM，会优先使用配置的 OpenAI/DeepSeek/本地 OpenAI-compatible 服务；未配置时使用本地规则解析，不需要网络。解析会生成 Shot 的人物、场景、动作、对白、旁白、景别、镜头运动、情绪和时长，并自动组合英文 Prompt。

## 4. 审核 Prompt 和 Shot

进入“生产中心”，在当前 Episode 的表格中检查镜头、状态和 Prompt。Prompt 由 Character、Scene、Action、Camera、Lighting、Style、Quality 七段组成；可以直接编辑。锁定后再次分析不会覆盖。每次系统或用户修改都会增加 `prompt_version`，历史可通过 API 查询并回滚。

## 5. 生成关键帧和选择候选

点击“开始关键帧生产”。系统会先检查 Prompt、工作流、ComfyUI；缺失项会列出并阻止提交错误任务。默认每个 Shot 生成 2 个候选，但仍按 RTX 4070 单任务串行，不会批量并发占满显存。

关键帧完成后状态为 `ImageReview`。选择候选后点击“选关键帧并生成视频”，只有被选中的图片才会进入 I2V。关键帧 QC 会检查文件、尺寸和可解码性，失败最多按任务重试策略重新生成。

## 6. 生成视频、审核和重试

I2V 状态依次为 `VideoGenerating`、`VideoReview`。视频 QC 通过 FFprobe 检查文件、时长、宽高、FPS、编码和异常空视频，并保存 0-100 基础质量分。人工可以给 1-5 星评分。

任务中心显示 GPU 峰值、耗时、失败原因分类和重试按钮。常见分类为 `CUDA_OOM`、`COMFYUI_OFFLINE`、`WORKFLOW_ERROR`、`MODEL_MISSING`、`INPUT_MISSING`、`FFMPEG_ERROR`、`TIMEOUT`、`QUALITY_FAILED`。OOM 重试会自动降低分辨率/帧数；不会重启 ComfyUI。

## 7. 配音、字幕、音效和 BGM

“声音”页面使用 Windows 本地 System.Speech。选择中文系统音色并输入对白可加入 CPU TTS 队列；相同文本、音色、语速、音高会复用 `AudioCache`。人物默认 `voice_id` 和 Episode 的旁白音色存放在数据库。

使用 `POST /api/episodes/{episodeId}/subtitles` 可根据 Shot 的 dialogue/narration 生成 UTF-8 SRT，时间轴按 Shot 顺序和时长重算。字幕文件保存在 `C:\install\AI\Data\Output`。

“音效 / BGM”页面允许上传 wav/mp3/ogg/flac，分别保存到 `C:\install\AI\Data\SoundEffects` 和 `C:\install\AI\Data\BGM`，数据库记录 SHA256。当前阶段不自动生成音效；BGM 在 Episode 合成时通过 FFmpeg 混音，默认降低 BGM 保证人声优先。

## 8. 合成完整 Episode

确认所有 Shot 已有通过 QC 的视频后，点击“合成 Episode”。后端按时间线排序，统一 30FPS，拼接到 `C:\install\AI\Data\Output`；如已生成字幕或传入音频轨道，还会执行字幕烧录和音频混音。最终标准为 MP4/H.264/1080P/30FPS。

## 9. 断点续跑

停止或重启电脑后再次运行 `start.bat`，队列会把数据库中遗留的 `Running` 恢复为 `Pending`，已完成结果不会自动重复生成；任务依赖会阻止上游失败的下游任务。生产中心和任务中心可继续查看、取消、重试或单独重跑 Shot。

## 10. 诊断命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\install\AI\VideoStudio\scripts\test_production_pipeline.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\install\AI\VideoStudio\scripts\test_production_pipeline.ps1 -RunRealGeneration
powershell -NoProfile -ExecutionPolicy Bypass -File C:\install\AI\VideoStudio\scripts\backup.ps1
```

第二个命令会真实占用 GPU 并等待至少两个视频结果，首次运行前请确认 ComfyUI、模型和数据库均在线。普通回归不需要重复生成已通过的 Shot。
