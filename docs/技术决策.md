# DEC-001

## 决策

使用现有 MySQL 作为主要数据库和任务状态权威来源。

## 原因

项目需要保存项目、Episode、Shot、资产、任务、Prompt、QA、审核和操作日志，并在服务重启/新会话后恢复；内存或聊天记录不能保证一致性。

## 影响

数据库变更必须通过备份和迁移；不能手工修改任务或 QA 状态冒充完成；Redis/内存不是当前事实来源。

## 状态

已采用

## 日期

2026-08-09

## 相关模块

server/Database.cs、database/database.sql、database/migrations、GenerationQueue

# DEC-002

# DEC-003

## 决策

使用现有本地 ComfyUI 和外部 AI 目录，不在 VideoStudio 仓库复制模型、Python、Git、FFmpeg 或生产媒体。

## 原因

## 影响

# DEC-004

## 决策

RTX 4070 12GB 上 GPU 任务并发固定为 1；I2V 源视频优先 512×320、24 FPS、73/97/121 帧，最终 1080P/30 FPS 由 FFmpeg 完成。

## 原因

当前显存和模型能力决定稳定性优先于直接高分辨率视频生成。

## 影响

不得默认引入需要 24GB 以上显存的模型；OOM 时按帧数、分辨率、候选数/steps 降级并保留参数证据。

## 状态

已采用

## 日期

2026-08-09

## 相关模块

GenerationQueue、ComfyUiClient、Workflows、docs/COMFYUI_API.md

# DEC-005

## 决策

生产任务必须真实提交 ComfyUI/FFmpeg/TTS，并以实际输出、FFprobe、数据库结果和 QA 推进状态。

## 原因

文件存在或代码已写不能证明生成成功；需要区分模型失败、输入失败、FFmpeg 失败、QA 失败和人工判断。

## 影响

失败任务保留错误分类、尝试次数、输出和日志；自动回炉最多两次，只回炉失败 Shot，并改变与原因相关的参数。

## 状态

已采用

## 日期

2026-08-09

## 相关模块

GenerationQueue、VideoQaServices、scripts/test_production_pipeline.ps1、scripts/qa_test.ps1

# DEC-006

## 决策

默认部署边界保持本机回环监听；未完成认证、CSRF、权限、路径安全、限流、审计和恢复验收前，不开放局域网或公网。

## 原因

当前 API 无完整认证授权，CORS 过宽，多个文件路径和 LLM 出站边界尚未闭环。

## 影响

本机受监督研发可继续；任何扩大监听范围的变更都必须先新增安全决策和负向验收。

## 状态

已采用；局域网/公网 No-Go

## 日期

2026-08-09
