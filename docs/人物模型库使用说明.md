# 人物参考库使用说明

入口：工作台左侧「人物参考库」及「剧情选角与试片」。本库保存人物设定、参考照片和不可变造型版本，不表示已经训练专属模型或建立三维人物。林安、周言旧九图和旧片继续可用；新增剧情链路已完成有限技术验收，最终人物内容与发布资格仍待审核，见[2026-10-27验收记录](CHARACTER_STORY_ACCEPTANCE_20261027.md)。

## 人物创建、定型与剧情路径

1. 点击「人物创建与定型」，选择项目，补齐姓名、年龄、脸部特征、发型发色、体型、基础服装、鞋子、固定外貌描述及禁改特征。同一个人物换衣服，应建立新造型版本。
2. 用现有RealVisXL生成少量正面近景候选；从真实成功任务收集候选，在原图中比较。先人工批准正面身份锚点，再由Klein派生正面全身基准并确认服装、体型和鞋子。其他角度沿用身份与造型基准，不能逐图独立文生图换脸。
3. 每个九图槽位可单独补图/修复。失败候选先记录拒绝原因，再提供原任务、不同种子或定向提示词；每槽最多两次修复。纠正用途时保留原请求、原标注和原因。来源参数可在候选详情查看。
4. 逐图人工审核后选择九个槽位，冻结人物/造型版本。九槽齐全与内容合格分别检查；未批准候选仍是草稿。五位扩充人物目前在候选区，可查看40张已有图片；5个全身前侧槽位仍缺，未当作已入库演员。
5. 在「剧情选角与试片」选择原有项目，将剧情角色映射到具体人物造型版本；明确采用到本集，再为原Shot绑定方向、景别、站位、动作、场景、机位和道具。项目/人物库更新不会自动替换本集或旧Shot的固定版本。
6. 先制作剧情关键帧，检查脸、衣服、身体、手部和道具关系；双人须分别绑定两个身份和造型，静态未通过不能生成视频。检查通过后，H3使用该关键帧的真实输出作为首帧。助手试片检查与人工最终审核分开，不能以Succeeded代替内容审核。
7. 按镜头检查视频，失败只修该镜头，最后通过CPU队列合成送审预览。选择原生声音、已有配音或后期配音，后两者移除原生人声，避免重复配音。技术、内容和发布资格分别记录。

010/011已由管理员执行并核验。本轮4个基础剧情片及定向修复已完成技术检查，可在[统一试片入口](http://127.0.0.1:18080/character-story-preview.html)查看实际关键帧、视频及保留失败。四输入Klein首次双人失败、提示修复后才可试片，不能据此保证普遍身份可靠；H3 Ref2VA未启用，FL2VA首尾帧不等于多身份参考。相同seed不保证身份一致。

下面的上传、旧版保存与直接人物参考图试片入口继续保留；直接试片属于实验路径，剧情镜头优先走上面的关键帧流程。

## 建立人物

1. 在「角色资产」创建角色，选择一个归属项目，填写外貌和固定提示词。固定提示词尽量描述五官、发型、体型；服装放在造型说明中，方便以后换装。
2. 上传已经检查过的人物图片。正面、侧面等视角分别上传，图片中的人应当保持一致。
3. 进入「人物参考库」，点击「保存人物版本」，选择角色，填写造型名称、完整服装（包括裤装与鞋子）和体型比例，为本版本使用的每张参考图分别指定视角、景别。
4. 明确选择480p或768p试用规格，保存版本。缺少的视角需要补图并保存新版本，系统不会擅自换成其他图片。

人物版本保存人物设定、参考图、声音档案和视频路线。修改角色档案后，已经保存的旧版本仍可调用；更新参考、造型或视频路线时应保存新版本。有库版本的源角色不能直接删除。

## 基础九图参考包

林安v3、周言v2已分别保存以下九张图，卡片显示「基础参考9/9」。点击「查看参考图」可以看完整九图，点击单图放大。

| 景别 | 必需视角 |
| --- | --- |
| 面部近景，3张 | 正面、左前侧、右前侧 |
| 全身，6张 | 正面、左前侧、左侧、背面、右侧、右前侧 |

左、右按画面中的朝向标注：鼻尖朝画面左为左侧，朝画面右为右侧；背面不露正脸。前侧为大约45度，侧面为大约90度；生成图不属于精确标定的三维模型。

全身图应完整露出头发、手脚和鞋子，并留出画面边距。近景图重点保证五官细节，不要把全身服装、鞋子的要求混入近景构图。不同角度应保持同一套衣服、鞋子、发型与体型，优先从同一身份锚点和正面全身造型派生。

保存时勾选「要求基础9图齐全」，缺少任一组合会禁止保存。同一个版本允许分别保存「正面＋面部近景」与「正面＋全身」，相同组合不能重复绑定。可另存半身或左后侧、右后侧参考，但不计入这九个必需位置。旧版本继续保留，原先未标景别的参考在页面按半身显示；旧版「全身」若没有方向，不会自动当成正面全身。

## 从人物库生成视频

1. 选择人物卡片中的版本。
2. 选择视频的目标项目、参考视角和参考景别；同一个人物版本可以在其他项目中选择使用。新版本必须明确景别，系统精确使用该组合的图片，缺图会拒绝调用。
3. 填写这次镜头的动作、表情和镜头描述。
4. 点击「预览本次调用」，检查人物、版本、实际参考图、视角、景别和输出规格。更换人物版本、角度、景别或动作后需要重新预览。
5. 点击「生成此人物视频」。任务串行执行，提交后按钮锁定；网络异常时重复提交会复用相同请求标识。
6. 在「人物库调用记录」点击任务，查看状态和播放视频。需要取消任务时可到原有「任务中心」操作。

本机H3生成较慢。本轮480p/24FPS/124帧短片约5.17秒，首条实测耗时约9分49秒；实际耗时以任务记录为准。先用小动作镜头确认人物，再考虑长视频或更高分辨率。

## 看结果时检查什么

- 脸、发型和服装是否与参考相符。
- 眨眼、微笑、轻点头等动作是否自然，有没有脸部跳变。
- 正面和侧向镜头是否仍像同一个人物。
- 全身动作中，裤装、鞋子、手脚与体型是否稳定，头和脚有没有被裁掉。

本期的视频调用用于人物外貌和造型复用验证。声音档案随版本保存；指定角色配音、精细口型和多人表演仍沿用既有流程，需另行验收。

技术生成成功表示文件和调用流程通过检查。人物自然度、艺术效果和最终使用决定仍需用户确认；试用视频不会自动成为正式成片或获得发布批准。

九图参考包支持按镜头选图，并不等于已经训练了专属LoRA或构建了三维人物。完整转身、长距离走动和复杂肢体仍应先做短镜头验证，再决定是否使用。
